# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of Request Cinema seriously. If you believe you have found a security vulnerability, please do NOT file a public issue.

Instead, please send an email to `security@ad-astrainc.com` or use GitHub's private vulnerability reporting feature.

### Information to Include
- Detailed description of the vulnerability.
- Steps to reproduce or proof-of-concept payload.
- Potential impact and affected components.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure plan.
