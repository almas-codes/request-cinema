# Accessibility Compliance (WCAG 2.2 AA)

Request Cinema is engineered to be accessible to all developers:

## 1. Accessible Table Alternative
For screen reader users and keyboard-only operators, the entire visual metro canvas has a 1-to-1 accessible tabular representation accessible via key `T` or the navigation button.
- Native HTML `<table>` with semantic `<thead>`, `<tbody>`, `scope="col"`, and `role` attributes.
- Sortable headers with keyboard controls.

## 2. Reduced Motion Support
- Users with `prefers-reduced-motion: reduce` or who toggle reduced motion mode in settings have continuous animation replaced with stepped discrete updates.

## 3. Color-Blind Safe Palette
- Pressing `C` or clicking the eye icon toggles the standard color ramp to a color-blind safe high-contrast palette (Teal -> Amber -> Purple).
- Error spans are additionally differentiated with icons (`AlertTriangle`, pulse shapes) so color is never the sole information carrier.
