## Key Features

- **Subway/Metro Transit Metaphor**: Services are stations, RPCs and messaging queues are subway tracks, and requests travel as trains.
- **Latency Percentile Heat**: Trains shift from blue/teal to warning amber and emergency crimson based on duration percentiles.
- **Derailment Physics**: Spans with error status code trigger visual derailment smoke and sparks.
- **Integrated Source Inspector**: Jump directly from a span or derailed train to your local source code with line highlighting and Git blame.
- **Zero-Server Browser Mode**: Drag-and-drop raw OTLP JSON files to analyze traces directly inside your browser.
